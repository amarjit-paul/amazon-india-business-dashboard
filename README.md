# Amazon India Business Dashboard

## Project Overview

An interactive business analysis dashboard developed using
Microsoft Excel to analyze Amazon India sales and operational
performance.

## Business Objectives

1. Overall Sales & Profit Performance
2. Category & Product Performance
3. Order Status & Revenue Loss
4. Payment, Fulfillment & Geographic Performance

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Data Analysis
- Data Visualization

## Key Analysis

The dashboard analyzes:

- Sales and profit trends
- Category and product performance
- Order status
- Returns and cancellations
- Payment methods
- Fulfillment methods
- Geographic performance
